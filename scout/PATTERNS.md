# Библиотека приёмов

Каждый приём снят с реального ролика, который Claude посмотрел покадрово (раскадровка YouTube, кадр ≈ 1 с). У каждого: что это, почему работает, откуда взят и готовый кусок кода под наш движок.

Движок напоминание: сцена — HTML, всё состояние — чистая функция времени `t`. GSAP используется только через **приостановленный таймлайн и перемотку** `tl.time(t)` — перемотка детерминирована, проверено.

```js
const tl = gsap.timeline({ paused: true });
// ... приёмы ниже добавляют шаги в tl ...
window.seek = t => tl.time(t);
window.META = { FPS: 30, DUR: tl.duration(), FRAMES: Math.ceil(tl.duration() * 30) };
```

Палитра канала: фон `#0F0F0F`, деньги `#2FD38E`, потеря `#FF4D4F`, текст `#FFFFFF`, золото `#F5C542`. Шрифт — Golos Text Black для чисел и титров.

## P-01. Лицо → окошко

**Что:** первые ~3 секунды — говорящая голова во весь кадр, хук голосом. Потом лицо сжимается в окошко внизу кадра (≈30% высоты), а верхние ≈70% забирает инфографика. Лицо остаётся в кадре до конца.

**Почему работает:** хук от живого человека цепляет сильнее, чем текст. А дальше лицо в окошке решает требование Instagram: ролики, которые «в основном текст», понижаются в выдаче. В кадре всегда есть движущийся человек.

**Откуда:** Кокорев, «Что можно было купить на миллион в разные годы» — 476 тыс. за 3 дня, 149 тыс./сут. Кадры 0–2 полный план, с кадра 3 окошко внизу.

**У нас:** Ланской из Omni Flash во весь кадр на хуке → уезжает в окошко. Готовый формат для роликов «с Ланским», и одновременно лечение инфографики от «majority text».

```js
// <video id="host" src="lanskoy.mp4"> на весь кадр 1080×1920
const host = document.getElementById('host');
host.style.transformOrigin = '50% 100%';
tl.to(host, { duration: 0.55, ease: 'power3.inOut',
  scale: 0.34, y: -60, borderRadius: 40 }, 3.0);          // на 3-й секунде уезжает вниз
// видео синхронизировать с t отдельно: host.currentTime = t  (в seek)
```

## P-02. Одна метафора количества на весь ролик

**Что:** количество показывается сеткой одинаковых жёлтых плашек. За весь ролик метафора не меняется ни разу — меняется только число плашек.

**Почему работает:** зритель понимает историю без звука. Уменьшение сетки читается мгновенно, мозгу не надо переводить число в смысл.

**Откуда:** тот же ролик, кадры 3–37. Жёлтый блок = условная единица покупательной способности.

```js
// сетка n плашек, каждая выскакивает с отскоком, каскадом
function blocks(parent, n, at, cols = 3) {
  const els = [];
  for (let i = 0; i < n; i++) {
    const b = document.createElement('div');
    Object.assign(b.style, { position: 'absolute', width: '118px', height: '118px',
      left: `${(i % cols) * 132}px`, top: `${Math.floor(i / cols) * 132}px`,
      background: '#F5C542', borderRadius: '10px', transform: 'scale(0)' });
    parent.appendChild(b); els.push(b);
  }
  tl.to(els, { scale: 1, duration: 0.32, ease: 'back.out(2.2)', stagger: 0.035 }, at);
  return els;
}
```

## P-03. Вертикальная ось времени, строки остаются

**Что:** годы идут строками сверху вниз — 1990, 2000, 2010, 2020, 2026. Каждый год раскрывается по очереди, а прошлые строки **остаются на экране**. Число плашек в каждой следующей строке меньше.

**Почему работает:** развязка — это сравнение. Когда последняя строка появляется рядом с первой, падение видно целиком, и говорить про него уже не нужно.

**Откуда:** тот же ролик. Первая строка — полная, последняя — почти пустая и красная.

```js
// rows: [{year:'1990', n:12}, {year:'2000', n:9}, ...] ; step — секунд на строку
rows.forEach((r, k) => {
  const at = 4 + k * step;
  const row = document.getElementById(`row${k}`);
  tl.from(row.querySelector('.year'), { opacity: 0, x: -40, duration: 0.3, ease: 'power2.out' }, at);
  blocks(row.querySelector('.grid'), r.n, at + 0.15);
});
```

## P-04. Нижний титр каждые 1–2 секунды

**Что:** под графикой постоянная строка — белый капс, максимум две строки. Меняется каждые 1–2 секунды и дублирует голос короткими кусками: «14,3 КИЛОГРАММА ЗОЛОТА», «270 ЛЕТ ЖИЗНИ», «ИЛИ 9415 АКЦИЙ СБЕРБАНКА».

**Почему работает:** держит тех, кто смотрит без звука. И создаёт ощущение, что на экране всё время что-то происходит, даже когда график стоит.

**Откуда:** тот же ролик, а также все ролики Кокорева — это его постоянная механика.

```js
// cues: [[t, 'ТЕКСТ'], ...] — тайм-коды берутся из align.py
const cap = document.getElementById('cap');
cues.forEach(([at, text], i) => {
  tl.call(() => { cap.textContent = text; }, null, at);           // смена текста
  tl.fromTo(cap, { y: 14, opacity: 0 }, { y: 0, opacity: 1, duration: 0.18, ease: 'power2.out' }, at);
});
```

Важно: `tl.call` при перемотке назад не откатывается. Для детерминизма в `seek(t)` дополнительно выставлять текст по последнему `cue`, у которого `at <= t`.

## P-05. Красный — только для панчлайна

**Что:** красный цвет в ролике появляется ровно дважды: на главном числе в заголовке («НА 1 000 000») и на значениях последней строки в самом конце. Всё остальное — белое и жёлтое.

**Почему работает:** красный не размазан, поэтому, когда он появляется в конце, это читается как сигнал «вот ответ».

**Откуда:** тот же ролик, кадры 35–37 — значения 2026 года перекрашиваются в красный.

```js
tl.to('#row4 .val', { color: '#FF4D4F', duration: 0.25, ease: 'none' }, finale);
tl.fromTo('#row4 .val', { scale: 1 }, { scale: 1.12, duration: 0.12, yoyo: true, repeat: 1 }, finale);
```

## P-06. Иконки-единицы в шапке

**Что:** под заголовком — ряд из трёх маленьких иконок (купюры, слиток, галочка). Они обозначают единицы, в которых идёт счёт, и висят весь ролик.

**Почему работает:** зритель в любой момент видит, что именно считают. Не надо держать это в голове.

**У нас:** иконки из установленных наборов Lucide / Tabler / Phosphor (`banknote`, `gem`, `circle-check`), перекрашенные в палитру. Отрисовка штрихом при появлении:

```js
// svg-иконка со stroke; длину штриха берём из getTotalLength()
document.querySelectorAll('#units path').forEach((p, i) => {
  const L = p.getTotalLength();
  p.style.strokeDasharray = L;
  tl.fromTo(p, { strokeDashoffset: L }, { strokeDashoffset: 0, duration: 0.5, ease: 'power2.inOut' }, 3.2 + i * 0.12);
});
```

## Как пополнять

Новый приём добавляется сюда только если его **посмотрели**, а не прочитали про него. Формат тот же: что, почему работает, откуда (ролик, просмотры, номера кадров), код. Номер — следующий по порядку, старые не переписываются.
