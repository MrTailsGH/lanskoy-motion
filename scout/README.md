# Разведка приёмов

Папка, куда складывается всё, что Claude находит у других: темы, хуки, приёмы вёрстки и анимации, переходы. Отсюда Claude в Code-вкладке берёт материал для новых роликов.

Запускается по команде пользователя — «сканируй». Автозапуска нет, это решение пользователя.

## Что здесь лежит

| Файл | Что это | Как пополняется |
|---|---|---|
| `PATTERNS.md` | **Библиотека приёмов** — что, почему работает, откуда, готовый код под наш движок | дописывается каждым сканом, старое не переписывается |
| `FINDINGS-ГГГГ-ММ-ДД.md` | отчёт одного скана: что посмотрено, что вынесено, что не открылось | новый файл на каждый скан |
| `scout.py` | инструмент: раскадровки, контактные листы, техприёмы | — |

**В Code-вкладке перед новым роликом читать `PATTERNS.md` целиком и последний `FINDINGS`.**

Контактные листы (картинки кадров чужих роликов) в репозиторий **не** кладутся — это решение пользователя. Они живут на его диске: `C:\MotionCapture\scout-shots\`.

## Как Claude «смотрит» ролик

Звук и движение между кадрами Claude не воспринимает, но видит кадры. YouTube хранит для каждого ролика **раскадровку** — сетку кадров по всей длине, примерно кадр в секунду. `scout.py` скачивает её, режет на кадры и собирает контактный лист: весь ролик на одной картинке с номерами кадров. По листу видно структуру, смену сцен, вёрстку, палитру, где появляется число и чем ролик закрывается.

```bash
pip install --break-system-packages -U yt-dlp
npm install -g deno                           # JS-движок, без него часть клиентов не работает
python3 scout.py watch <videoId> <videoId>    # контактные листы → ./sheets/
python3 scout.py targets 6                    # цели из ../radar/RADAR.md
python3 scout.py tech                         # свежие техприёмы Codrops и Vimeo
```

## Порядок скана

1. `cd ../radar && python3 radar.py --report RADAR.md` — свежий радар, коммитить `history.json`.
2. Выбрать 2–4 цели: выбросы по индексу и свежие взлёты **в нашей полосе**. Криминал, политику и науку не брать.
3. `python3 scout.py watch ...` — контактные листы. Открыть каждый и разобрать.
4. Если контейнер получает бот-проверку — те же ролики открыть в Brave.
5. Новые приёмы → `PATTERNS.md`, отчёт → `FINDINGS-<дата>.md`, листы → на диск пользователя.
6. Коммит папки `scout/` и истории радара.

## Ограничения — проверено 25.09.2026

**YouTube душит по IP.** Раскадровки через `yt-dlp` отдаются, но после нескольких запросов подряд IP контейнера получает «Sign in to confirm you're not a bot» на всех клиентах, а затем `LOGIN_REQUIRED` уже в HTML страницы ролика. Отказ временный. Поэтому — пачки по 2–4 ролика с паузами, не десятки. `scout.py` сам перебирает пять клиентов (`web_safari`, `mweb`, `web`, `ios`, `tv_simply`) и ждёт между попытками.

**Страницы каналов радару отдаются всегда** — ограничение касается только данных плеера.

**Браузер может уйти на капчу** (`google.com/sorry`) — особенно через VPN. Капчу проходит только пользователь.

**Из контейнера закрыты:** Behance, Reddit, LottieFiles (403), Dribbble (антибот-заглушка), TikTok и Instagram (без входа). Эти источники — только через Brave пользователя.

**Открыты из контейнера:** YouTube (страницы каналов, RSS), Codrops, Vimeo Staff Picks.
