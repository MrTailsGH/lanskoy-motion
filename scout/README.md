# Разведка вне YouTube

Всё, что можно взять у других для наших роликов, **кроме YouTube**: приёмы анимации, переходы, дизайн карточек и интерфейсов, иконки, форматы коротких роликов из TikTok и Reels.

**YouTube сюда не входит.** Чужие шортсы снимает `snimok.py`, замеряет `razbor.py`, первые секунды разбирает `hooki.py`, выводы и приёмы — в **`PRIYOMY.md`** в корне. Одна библиотека приёмов на весь проект, эта папка её не дублирует.

Запускается по команде пользователя — «сканируй». Автозапуска нет, это решение пользователя.

## Источники и как их смотреть

Проверено 25.09.2026 на домашнем компьютере, Brave с расширением Claude in Chrome.

| Источник | Что берём | Как смотреть | Статус |
|---|---|---|---|
| **Dribbble** | анимация интерфейсов, счётчики, переходы экранов | браузер находит ссылку на `.mp4`, контейнер качает → `motion.py` | ✅ |
| **Behance** | моушн-кейсы, раскладки, палитры | браузер находит `.gif`/`.mp4`, контейнер качает → `motion.py` | ✅ |
| **LottieFiles** | микро-анимации, точные кривые разгона | браузер находит `.lottie`, контейнер качает → `lottie_scan.py` | ✅ |
| **TikTok** | форматы, хуки, что держит | нужен вход в TikTok в Brave; кадры — `sheet.js` на странице | ✅ |
| **Instagram Reels** | то же, плюс воронка через комментарии | нужен вход; видео отдаётся как `blob:`, кадры — `sheet.js` | ✅ |
| **Codrops** | разборы переходов и анимации с кодом | из контейнера: `python3 scout.py`, статьи — WebFetch | ✅ |
| **Vimeo** | фильмы, визуал | расширение пишет «Navigation to this domain is not allowed»; список из RSS — `scout.py` | ⚠️ только список |

**Доступ расширения к сайтам.** В меню расширения в Brave должно стоять «Расширение может получать доступ к данным сайта → На всех сайтах». С настройкой «При нажатии на расширение» TikTok не открывался.

## Инструменты

```bash
# видео или GIF с Dribbble / Behance — контактный лист и события движения
python3 motion.py <url> <out-префикс> --sheet-fps 5 --tile 170 --title "..." [--crop x0,y0,x1,y1]

# Lottie — кривые разгона, длительности, каскады + покадровая отрисовка
npm install lottie-web          # один раз, рядом со скриптом
python3 lottie_scan.py <url .lottie|.json> <out-префикс> "название"

# свежие статьи Codrops и Vimeo
python3 scout.py
```

`--crop` — доли кадра. Нужен, когда шот Dribbble показан маленьким телефоном на большом холсте: обрезка делает детали видимыми, а замер движения точнее.

**`sheet.js` — кадры TikTok и Reels.** Ссылки на видео с подписью расширение не отдаёт, это его защита — не обходить. Поэтому скрипт выполняется прямо на странице ролика: берёт видео в центре экрана, перематывает его по шагам (длина ÷ 30) и рисует контактный лист поверх страницы. Дальше — один скриншот области листа. На TikTok на странице два видео: следующее подгружается заранее, поэтому выбирать надо по центру экрана, иначе снимется чужой ролик.

## Порядок скана

1. Проверить доступ ко всем площадкам **сразу**, пока пользователь у компьютера: вход в TikTok, Instagram, GitHub, нет ли капчи.
2. `python3 scout.py` — свежее с Codrops и Vimeo.
3. Dribbble, LottieFiles, Behance — движение с точным временем. TikTok, Reels — форматы и хуки, выбирать по лайкам в выдаче.
4. Отчёт скана → `FINDINGS-ГГГГ-ММ-ДД.md` этой папки.
5. Лучшее → `PRIYOMY.md` в корне, следующим номером, в его стиле: «что», «почему работает», «как у нас». Старые номера не переписываются.
6. Контактные листы — **только на диск пользователя**, `scout-shots\` в подключённой папке, в репозиторий не кладутся. Это решение пользователя: чужие кадры в публичном репозитории — уже распространение чужого материала.

## Ограничения

**Капча и вход.** Капчу и вход в аккаунты проходит только пользователь — Claude в этот момент останавливается и ждёт.

**Нагрузка.** Не открывать десятки страниц подряд с одного сайта: антибот-защита срабатывает на частоту.

**Лицензии.** Приём — можно, ассет — нельзя. С Dribbble и Behance берём идею движения и раскладки, а не картинку. С LottieFiles — тайминги и кривые; сами файлы в проект не берём, пока не проверены условия Lottie Simple License.

**Точность замера.** `motion.py` грубее `razbor.py`: считает разницу соседних кадров по всему кадру. Мелкие движения на большом холсте недооценивает, медленные плавные — не видит вовсе.
