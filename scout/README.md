# Разведка вне YouTube

Всё, что можно взять у других для наших роликов, **кроме YouTube**: приёмы анимации, переходы, дизайн карточек и интерфейсов, иконки, форматы коротких роликов из TikTok и Reels.

**YouTube сюда не входит.** Чужие шортсы снимает `snimok.py`, замеряет `razbor.py`, первые секунды разбирает `hooki.py`, выводы и приёмы — в **`PRIYOMY.md`** в корне. Одна библиотека приёмов на весь проект, эта папка её не дублирует.

Запускается по команде пользователя — «сканируй». Автозапуска нет, это решение пользователя.

## Источники

| Источник | Что берём | Как попасть |
|---|---|---|
| **TikTok** | форматы, хуки, переходы в нише деньги/бизнес | только Brave пользователя |
| **Instagram Reels** | то же, плюс что держит досмотр в Reels | только Brave пользователя |
| **Dribbble** | анимация интерфейсов, карточки, счётчики | только Brave (из контейнера — антибот-заглушка) |
| **Behance** | моушн-кейсы, раскладки кадра, палитры | только Brave (из контейнера — 403) |
| **LottieFiles** | готовые микро-анимации иконок и состояний | только Brave (из контейнера — 403) |
| **Codrops** | разборы веб-анимации и переходов с кодом | `python3 scout.py` |
| **Vimeo Staff Picks** | лучшие короткие фильмы недели, визуал | `python3 scout.py` |

Проверено 25.09.2026.

## Порядок скана

1. `python3 scout.py` — свежее с Codrops и Vimeo.
2. В Brave пройти TikTok, Reels, Dribbble, Behance, LottieFiles по нише: деньги, налоги, бизнес, финансовая инфографика, анимация чисел и интерфейсов.
3. Каждую находку, которую **можно сделать у нас**, записать в `FINDINGS-ГГГГ-ММ-ДД.md` этой папки: что это, где видели, почему работает, как у нас.
4. Лучшее переносить в `PRIYOMY.md` в корне — следующим номером, в его стиле: «что», «почему работает», «как у нас». Старые номера не переписываются.
5. Картинки и скриншоты чужих работ — **только на диск пользователя**, `C:\MotionCapture\scout-shots\`, в репозиторий не кладутся. Это решение пользователя: чужие кадры в публичном репозитории — уже распространение чужого материала.

## Ограничения

**Капча.** Браузер может уйти на `google.com/sorry` или похожую проверку, особенно через VPN. Капчу проходит только пользователь — Claude в этот момент останавливается и ждёт.

**Нагрузка.** Не открывать десятки страниц подряд с одного сайта: антибот-защита срабатывает на частоту.

**Лицензии.** Приём — можно, ассет — нельзя. С Dribbble и Behance берём идею движения и раскладки, а не саму картинку. Анимации LottieFiles берём только с явной бесплатной лицензией и с указанием автора.
