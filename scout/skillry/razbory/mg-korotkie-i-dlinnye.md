- Direction: один элемент меняет размер, радиус и цвет. Контент меняется через «short blur». Каждое изменение вызывает курсор реальным кликом или драгом. Тёплый серый фон, Geist, «springs everywhere, a tiny overshoot at most». Камера зумит так, чтобы состояние заполняло кадр. Последний кадр равен первому.
- Бан: bouncy easing, частицы, glow, градиенты на UI-хроме, разнобой толщины обводок иконок, мёртвое время, «template»-вид.

  6. Playwright: 4 сабфрейма на кадр, ffmpeg `tmix`, 60 fps.

## 3. Технические рецепты

### Motion blur через сабфреймы
- Playwright рендерит **4 сабфрейма на выходной кадр**, ffmpeg блендит каждую группу из 4 (`tmix`) → 60 fps (thegrootdev, шаблон UI-морфа, techhalla, annacher).
- Вариант brainextends: **3–5 temporal subframes**, «restrained motion blur», неподвижные текст и арт остаются резкими. Блюр только в самой быстрой части зума.
- jake11moran: motion blur только «on fast moves».
- (адаптация) Для наших 30 fps: `seek` на `(n + k/4)/30`, k = 0..3, и блендинг группы в один кадр. Статичный текст от этого не пострадает, потому что его пиксели совпадают во всех сабфреймах.

### Пружины в замкнутой форме
- Closed-form step response вместо интегрирования физики.
- Значение, которое много раз меняет цель, = **сумма одной пружины на каждую смену цели**. Так оно остаётся чистой функцией t.
- Характер: «critically damped» (brainextends, gdgtify для оседающих грузов), «tightly damped… only a tiny overshoot» (thegrootdev), «tiny overshoot at most» (шаблон). У хука techhalla — «spring overshoot».
- **Две пружины на два края** (таб-индикатор, knob тоггла): передний край вытягивается вперёд заднего.
- Отпускание драга: пружина стартует с позиции **и скорости** в момент release.
- Per-glyph пружина по y, opacity и blur, stagger 125ms (1/16 при 120 BPM).

### Easing и тайминги
- `cubic-bezier(.16,1,.3,1)`: word pull-up 0.6s, шаг 0.08s, `translateY(20px)`; fade-up 0.8s с задержками 0.5 и 0.7s.
- «Медленный дорогой» стиль: движения камеры 1.5–3s на ease-in-out, «half the speed you'd default to».
- Большинство идей около 1s (brainextends). Пауза полной неподвижности ≥ 400ms (gdgtify).
- Вопросительный знак через 0.2s после посадки списка (jake11moran).
- Micro-breath финала: scale 1.000 → 1.012 → 1.000.
- Камера: только punch-in 1.0 → 1.08 и smash-pan по битам, без случайного дрейфа.
- «time-remapping curves and analytic transforms» (gdgtify).

### Бит-грид и синхронизация
- numpy оценивает сетку битов, **проверяет downbeat**, старт на downbeat. Если темп отличается от 120 BPM, тайминг подстраивается под фактический.
- 120 BPM, 4/4, 7 тактов = 28 битов ≈ 14s. В techhalla downbeat в t=0.
- Плотность: событие на каждом бите первые 16 битов, затем через бит.
- UI-звуки ставятся по **измеренному пику транзиента**, а не по началу файла.
- Для речи: cue sheet по фразам, паузам и акцентам, «Do not force the speech onto a dance beat». Биты графики синхронизируются с произнесёнными словами (stokebuilder).

### Звук
- Музыка: royalty-free ~120 BPM (пример Mixkit) с проверкой лицензии. brainextends: чистый пульс, тёплый бас, сдержанная мелодия, SFX тише музыки. Без копирайтных треков.
- **Синтез UI-звуков в numpy** без музыки (annacher).
- Драматургия саунд-дизайна: сдержанный пульс в начале → хиты на переходах → нарастание → разрешение (howdevelop).
- ElevenLabs API для sound design (anabology).
- Войсовер: «highest-quality text-to-speech model you can access» (astrothewizard). Browser speech synthesis запрещён, звук по умолчанию выключен (gdgtify).
- Микс: **музыка дакается под голос, мастеринг под стриминговую громкость, микс проверяется численно** (astrothewizard).
- Петля: звук тоже закольцован, лишние биты в конце обрезаются.

### Детерминизм и экспорт
- `async window.seek(t)`, любой кадр воспроизводим при любом порядке сика. Без CSS-transition, `setInterval` и React-state.
- Фиксированный шаг n/60 → 1200 кадров на 20s. Периодичность `render(0) = render(T)`.
- **Экспорт `[0, duration)` без дублирования конечного кадра.**
- Стык петли: геометрия, контент, камера, позиция и скорость курсора.
- Скрэмбл через **seeded** Fisher–Yates: случайность детерминирована.
- Все ассеты и шрифты зашиты в HTML, при рендере нет сетевых запросов.
- Проверить **равномерность таймстемпов** и точную длительность (brainextends).

### Проверка и QA
- Кадр на каждый бит или 8 стоп-кадров по главным битам до полного рендера. Чек: тесно, висячие слова, низкий контраст, мимо сетки, нечитаемо.

- Переходы кадр за кадром, стоп-кадр каждой сцены, повторный рендер слабого.
- Для текста: строка должна прочитаться до того, как трансформируется (gdgtify).
- Судья один раз по критериям бренд / интерес / релевантность / вкус, доработка только провального (stokebuilder).

### Типографика и маски
- Мисрегистрация: дубли текста ±2–4px в двух акцентных цветах, 40% opacity, только на кадрах удара.
- Маска-вайп контурами уходящего слова.
- Реальные глиф-пути с сохранением counters. Несвязанные слова переходят через окклюзию или общие грани, без интерполяции точек.
- Masked vertical reveals заголовков, typewriter-ввод в поиске (brainextends).
- Три роли шрифтов (дисплей / вторичный / моно), трекинг дисплея от −40 до −80, моно +20. «Крошки» ≤ 18 символов.
- Радиальная маска-«рентген»: 165px / feather 45px / `.12s linear`.
- Контент внутри морфящегося контейнера меняется через «short blur», у входа и выхода свои тайминги.

### Камера и рендер-ловушки
- Не ставить `will-change` на элементы, которые масштабирует камера: текст мылится.
- Камера переподгоняет кадр так, чтобы каждое состояние оставалось крупным и читаемым.
- Всё, что обрезается сценой, чисто клипуется по её скруглённой форме (brainextends).
- Для 16:9 важное держать в центральной зоне, безопасной для 9:16 (howdevelop).
- Лёгкое film grain в финале (jake11moran, параметров нет).

- Логическое разрешение 128×96, целочисленный апскейл, `imageSmoothingEnabled=false`, `image-rendering: pixelated`, палитра ~24 цвета.
- Параметры анимируются плавно и квантуются, чтобы движение ощущалось как 8–12 fps при 60 fps.
- Тряска 1–2px на ударе.
