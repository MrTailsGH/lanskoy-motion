## daniel-haida-636937 | Моушн | 0:14 | Canvas, SVG, CSS | промпт частичный

**Что это:** 15-секундный продуктовый фильм для Taxtello, немецкого приложения бухгалтерии. Сделан на React + Remotion, After Effects не использовался, саундтрек синтезирован в Python из синусов и шума. Автор пишет: «1 промпт и 2 раунда правок».

**Почему главный референс для нас:** это единственный на сайте промпт про **финансовый продукт на тёмном фоне** с жёсткой дисциплиной, и он по устройству ближе всех к нашему регламенту.

**Устройство промпта (по разделам):**

1. **Роль и планка.** «Senior motion designer, product designer and Remotion engineer». Три отрицания: не SaaS-эксплейнер, не прогулка по функциям, не шаблон. Желаемая реакция зрителя одной фразой: «Подождите, это немецкое приложение бухгалтерии?»
2. **Источник правды.** Сначала изучить реальный репозиторий, токены CSS, вордмарк и скриншоты. Не выдумывать функций, которых нет. Существующую анимацию не трогать, делать новую композицию рядом.
3. **Палитра — числами из токенов.** Фон `#0c0f1a`, три поверхности, золото `#e8b84b` / блик `#f5d07a` / глубина `#9b6d18`, текст `#e8eaf2`, вторичный `#8b93b5`, позитив `#34d399`, негатив `#f87171` «только где семантически нужно». Цифры — моноширинным (JetBrains Mono). «Золото — драгоценный акцент, а не жёлтый потоп». Словарь «да»: тёмный металл, тёплое золото, стекло, чернила, точность, спокойная уверенность. Словарь «нет»: киберпанк, крипта, неон, гейминг, AI-фиолетовый, радуга.
4. **19 правил, «соблюдать безжалостно».** Среди них: один план — одна идея; воздух в каждой сцене; UI — герой; без склеек встык без причины; переходы через предметы; элементы не стартуют и не останавливаются в один кадр; никаких частиц, стекла везде, лишнего блюра, 3D-вращения карточек, постоянного зума, 20 разных стилей, прыгающего UI и больших абзацев. «Уверенность — из сдержанности».
5. **Формат.** 1920×1080, 60 fps, ≤ 15 с. Должно работать без звука. Вертикаль — только **перекомпоновкой**, не кропом.
6. **Дуга.** «ХАОС → КОНТРОЛЬ → ЯСНОСТЬ → ТАКСТЕЛЛО» как одна непрерывная мысль, а не пять функций. Первые 1,5 с уже премиальные, первый продуктовый момент к ~2 с, никакого пятисекундного интро логотипа. Около четырёх визуальных идей на фильм.
7. **Раскадровка по секундам** — «сильная отправная точка, не шаблон». 0–1,2 золотой блик открывает знак → 1,2–4,4 кокпит собирается: главное число, график рисуется, метрики оседают позже → 4,4–7,5 точка графика становится углом чека, чек «примагничивается» к проводке → 7,5–10,7 счета: статус меняется, сумма встаёт на место → 10,7–12,8 налоги: шумные сигналы сходятся в один спокойный обзор, ритм замедляется → 12,8–15 камера отъезжает, UI складывается в один объект, вордмарк, одна строка. Подписи 3–4 слова, по желанию.
8. **Переходы — «самое важное».** Хорошо: линия графика → край документа; золотая пилюля → кнопка счёта; число → сумма в счёте; прорыв камеры сквозь элемент; общая геометрия; маска формой продукта. Плохо: кроссфейд, случайная шторка, вращение, глитч, whip-pan каждые 2 с, «слайд влево», зум-блюр.
9. **Движение.** `cubic-bezier(0.16, 1, 0.3, 1)`, перелёт < 2%, разное время прихода у разных элементов, общая скорость между сценами. «Как дорогая макросъёмка физического предмета».
10. **Звук.** Сетка 115–120 BPM. Мягкий низкий удар на главном раскрытии, сдержанные тактильные клики, тонкий металлический тик, разрешающий тон на логотипе. Запрет: трейлерный бум, EDM-райзеры, вуши везде, сток «tech interface». Нет легальной музыки — не тянуть из интернета, отдать фильм без музыки и cue sheet.
11. **Только реальный продукт.** Не выдумывать экраны и метрики, похожие на данные клиентов. Демо-значения — явно синтетические. Экран пересобрать в коде из дизайн-системы, а не масштабировать скриншот.
12. **Не останавливаться на первой версии.** Порядок работы: изучить → раскадровка с таймкодами → код → проверки → **10 кадров** на 0,0 / 1,0 / 2,5 / 4,5 / 6,5 / 8,5 / 10,5 / 12,5 / 14,0 / 14,8 с → посмотреть глазами по списку вопросов → починить → полный рендер → смотреть **декодированные кадры из MP4**, а не скриншоты браузера → ещё круг.
13. **Отвергнуть своё, если похоже на:** SaaS-шаблон, PowerPoint, запись экрана сайта, демо Remotion, рекламу крипты, «пять скриншотов ездят». «Лучше 3 выдающихся момента, чем 10 средних».
14. **Сдача.** Раскадровка, исходник, MP4, постер, контакт-лист, точная длительность, список использованных ассетов, объяснение языка движения, оставшиеся компромиссы, команды для повторного рендера.

**Что взять (адаптация для Ланского):**

- Наша палитра устроена так же: тёмный фон, акцент ≠ заливка, зелёный и красный только по смыслу. Их формулу «акцент — драгоценность, а не потоп» стоит записать как правило для бирюзового.
- Дуга «хаос → контроль → ясность» ложится на ролики про налоги и учёт.
- Переходы через предметы — ровно наш `PER.graph` («новый акт из-под линии графика»). Их список «хорошо/плохо» можно брать как чек-лист при выборе перехода.
- Шаг «смотреть кадры из готового MP4, а не из браузера» — добавить в приёмку: кодирование иногда портит тонкие линии и градиенты.
- Вертикаль — перекомпоновкой, не кропом. У нас вертикаль основная, так что правило обратное: горизонталь делать перекомпоновкой.

## alexwtlf-981005 | Моушн | 0:22 | Canvas | промпт полный

**Что это:** промпт для **генеративной видеомодели** (фотореал, ссылки на персонажей через `@`), а не для кода. Короткий фильм: ночная сторона Земли, девушка у иллюминатора станции, астронавт снаружи на фале, метеорит, удар, одна слеза. 25 с, семь склеек между двумя позициями камеры.

**Устройство** — образец того, как держать генеративную модель в рамках:

- **Карта места** до действия. Размеры задаются **относительно друг друга**: иллюминатор ~50 см, голова девушки — половина его диаметра, шлем — две трети ширины, окно — четверть роста астронавта. Где Земля, где лимб, где точка удара, в какой трети кадра стоит герой.
- **Геометрия зафиксирована на весь фильм**: что слева и что справа с каждой камеры; удар никогда не в кадре снаружи, только отражения.
- **Первый кадр — уже в движении**, с описанием позы.
- **Склейка за склейкой по секундам**, с последним кадром каждой склейки. Склейки 6 и 7 возвращаются **ровно** в кадровку склеек 4 и 3.
- **Оптика и камера по склейкам**: 24 / 35 / 40 / 50 мм, глубина резкости, «locked с дрейфом в несколько пикселей», дрожь только от ударов ладонью и затухает за полсекунды.
- **Физика и свет числами**: ключ 5600 K, заполняющий 2800 K, огонь 2400 K. Растёт медленно: «точка → перчатка → шлем → два шлема → три шлема за четыре секунды, дальше ничего».
- **Игра актёров** — дуга по состояниям («дурачится, играет, замечает, замирает, тревожится, в панике, смотрит, сломлена»), и что лицо **не** делает.
- **Звук**: одна подложка внутри станции на весь фильм; удар беззвучен, потому что снаружи вакуум.
- **POSITIVE LOCKS** — длинный список того, что должно быть **всегда** и **никогда**: один метеор, без искр и частиц, не больше шлема; ни текста, ни цифр в кадре; одна слеза только в последней склейке.

**Что взять:** если Ланскому понадобятся генеративные вставки (Kling, Veo и т. п.), это готовая форма ТЗ. Сначала карта места и относительные размеры. Потом геометрия, которую нельзя ломать. Потом склейки по секундам с последним кадром. В конце список «всегда / никогда». Кадры с текстом и цифрами генерации не доверять — только коду.
