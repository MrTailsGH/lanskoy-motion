# Skillry.dev / Opus 5.5 — разведка

https://skillry.dev/ai-videos/opus-5-5 — 475 роликов, которые сделал Claude Opus 5.5, рядом с каждым промпт, по которому он их сделал. Плюс каталог видео-скиллов skillry (https://skillry.dev/llms.txt). Разобрано целиком 30.09.2026.

**Со skillry берём только идею** — как с Dribbble, Behance, TikTok и Reels. Код, промпты, картинки и скиллы в ролики не идут. Платное не покупаем. Что-то отсюда попадает в готовые ролики только после «да» пользователя.

- Технологии: Canvas 336, SVG 193, Three.js 141, GLSL 100, GSAP 81, CSS 61, Web Audio 36.

- Склеек (медиана): моушн 8, эксплейнер 1, игры 2, 3D 1. Доля кадров покоя: эксплейнер 65%, моушн 46%.

- Для нас: ★★ 64, ★ 251, без звезды 160.
- Скиллы: 141 с выходом «видео», 8 бесплатных (нужен вход), 133 по $4.99. Требуют HyperFrames CLI 0.8.30, Node 22+ и FFmpeg. Вертикаль 1080×1920 основным форматом не заявлена ни у одного.

## Как снято

1. Листинг раздела отдаёт все 475 ссылок одной страницей. Страницы, медиа, `llms.txt` и `llms-full.txt` контейнер качает напрямую, браузер не нужен. `robots.txt` закрывает только `/auth`, `/admin`, `/api` и похожее.
2. `tools/fetch.py` качает страницы записей, по 3 потока с паузой. `tools/parse.py` вынимает промпт (блок `<pre>` после кнопки «Copy prompt»), пометку «часть промпта», технологии, длительности, ссылку на пост и медиа.
3. `tools/vids.py` качает `original.mp4` (~1,2 МБ, 1280×720 или 720×1280) и снимает с него ленту из 8 кадров. Там же считает склейки (средняя разница кадров > 40 на 10 fps, 64 px) и долю покоя (< 1,5). Одно видео не скачалось: `faroukzy-138551`, 4:00.
4. `tools/mosaic.py` складывает ленты листами по 16. Все листы просмотрены глазами: промпт часто не совпадает с роликом, поэтому в каталоге есть отдельное поле «видно».
5. Промпты прочитаны целиком. Разборы в `razbory/` писали субагенты по кускам `mg_00`…`mg_05`, отсортированным по длине промпта (эти имена встречаются в заголовках разборов). Кусок `mg_00` — два самых длинных — читал сам. Короткое описание каждой записи — тоже субагенты, 4 куска по ~120. `tools/build_kb.py` собирает `KATALOG.md`, `katalog.json` и личный `PROMPTY.md`.

Обновить — по команде пользователя, автозапуска нет:

```bash
cp -r scout/skillry/tools /tmp/skillry && cd /tmp/skillry   # вне репозитория: сюда лягут items/, frames/, mos/
curl -s https://skillry.dev/ai-videos/opus-5-5 -o page.html
grep -o 'ai-videos/opus-5-5/[a-z0-9-]*-[0-9]\{6\}' page.html | sort -u | cut -d/ -f3 > slugs.txt
mkdir -p items && python3 fetch.py && python3 parse.py && python3 vids.py
python3 mosaic.py "Motion graphics,Explainers"; python3 mosaic.py "3D scenes,Games"
# описания sum/out_*.tsv и vis.tsv — вручную или субагентом, потом:
python3 build_kb.py
```
