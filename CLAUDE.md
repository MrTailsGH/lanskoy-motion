# Ланской — моушн-цех. Точка входа для Claude

Этот файл читается автоматически при старте сессии Claude Code с этим репозиторием.
Пользователю достаточно написать «продолжаем» — дальше по этому файлу.

## Первым делом

1. **`OPERATIONS.md`** — полный регламент цеха: как рендерятся ролики, визуальный язык, озвучка, вёрстка вертикали, ограничения контейнера, все известные грабли. Ничего в проекте не менять, не прочитав его.
2. **`PACK-02-temy.md`** — разведка ниши, ВИРАЛ-СТАНДАРТ (правила Ф1–Ф10) и банк тем с фактчеком. По этому пишутся все новые сценарии.
3. **`radar/README.md`** — радар трендов, если задача про темы или про то, что сейчас собирает просмотры.

## Что это за проект

Канал коротких роликов-инфографик про деньги, бизнес и налоги. Ведёт AI-персонаж **Егор Ланской**. Вертикаль 1080×1920, горизонталь 1920×1080, всегда **30 fps**. Монетизация — воронка в Telegram, оттуда курсы и реклама.

Главное правило цеха: **сначала звук, потом картинка.** Длина ролика равна длине дорожки диктора, а не назначается заранее.

## Порядок работы над роликом

```
тема из PACK-02 → сценарий по Ф1–Ф10 → текст озвучки (Eleven Labs, голос Станислав, eleven_v3)
   → пользователь присылает mp3 → align.py даёт пословные тайминги
   → сцена .html под дорожку → render.py → ffmpeg → MP4
```

## Радар трендов

Лежит в папке `radar/`, документация — `radar/README.md`. Коротко:

```bash
cd radar && python3 radar.py --report RADAR.md
```

Без ключей и без браузера. Три метрики: **прирост** (что греется сейчас), **скорость** (просмотров в сутки), **индекс** (просмотры ÷ медиана канала — лучший источник идей).

**`radar/history.json` коммитить после каждого прогона** — без истории не считается прирост.

## Разбор чужих роликов

Радар говорит, **что** взлетело. `Primeri/` отвечает, **чем** это сделано.

```bash
python3 snimok.py --top 5 --push   # на домашней машине: качает и меряет
```

`razbor.py` меряет один ролик (склейки, анатомия переходов, доля покоя,
дрейф, громкость, плотность звука, темп речи по субтитрам), `svodka.py`
сводит все замеры в `Primeri/SVODKA.md` — это делает GitHub Actions сам.
Видео в репозиторий не кладём: едут кадры, субтитры и числа.

Из контейнера YouTube закрыт, и облачный раннер GitHub он тоже не пускает —
проверено пробой 20.09.2026, «Sign in to confirm you're not a bot». Поэтому
скачивание живёт на своём раннере (компьютер Егора), а управление — в
GitHub: воркфлоу «Снимок чужих роликов», расписание и кнопка. Как поставить
раннер — `RANNER.md`.

## Чего не делать

- Не открывать заново вопрос Remotion и GitHub Actions: рендер живёт в контейнере, это решено.
- Не ставить цифру в сценарий без нормы — номер закона или постановления с датой, подтверждённые двумя источниками. Требование пользователя, оно жёсткое.
- Не писать в тексте озвучки аббревиатуры, не оставлять составные числительные длиннее двух слов, не употреблять слово «стоит».
- Не начинать ролик с цифр: сначала постановка и обещание, потом разрыв ожидания.
- Не переписывать чужие файлы в репозитории без спроса.
