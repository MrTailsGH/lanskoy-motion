# Готовые ролики

Склад собранных MP4. Общей истории с `main` у этой ветки нет намеренно: вес
файлов не попадает в историю кода. Тридцать роликов по десять мегабайт были
бы там обузой навсегда.

Забрать ролик: открыть файл в GitHub и нажать **Download**, либо

```bash
git clone --branch renders --depth 1 https://github.com/MrTailsGH/lanskoy-motion.git
```

эффектов из пака: щелчки счётчика под набегающим числом, удар на итоге,
вспышка на смене акта. Серия щелчков подогнана под длину набора — цифра и
звук останавливаются вместе. Потолок громкости −1 дБ, клиппинга нет.
Финал переделан: вместо плашки с призывом — карточка профиля канала,
которая собирается по шагам, и адрес крупно в конце. Поэтому ролик длиннее
прежнего на две секунды.

## Старое

`videos/Skidka20_*.mp4` — два тестовых рендера от первого подхода, когда
ролик писался на React и собирался в GitHub Actions. К нынешнему конвейеру
отношения не имеют, лежат как след. Мешают — удалить.

## Правила склада

**Один файл на ролик, имя без версии.** Ролик перерендерен — файл заменяется
на месте, старый остаётся в истории ветки. Плодить `_v2`, `_v3`, `_final` не
нужно: для этого и есть git.

**Кириллицу в именах не использовать.** Веб-загрузка GitHub её иногда ломает.

**Сюда попадает только то, что пересобирается из репозитория целиком** —
сцена плюс дорожка, воркфлоу «Рендер ролика» или тот же конвейер вручную.
Ролик, который нельзя пересобрать, здесь не нужен.

Исходники, сцены и регламент — в ветке `main`, начинать с `OPERATIONS.md`.
