# Ланской — моушн-цех

Ролики-инфографика для YouTube Shorts, Reels и Telegram. Канал ведёт AI-персонаж **Егор Ланской**, ниша — бизнес, деньги, саморазвитие.

**Начинать с [`OPERATIONS.md`](OPERATIONS.md)** — там регламент цеха, устройство проекта, визуальный язык и все известные грабли. Этот файл только оглавление.

---

## Как это устроено

```
сценарий → текст озвучки → ElevenLabs (дорожка) → align.py (тайминги)
                                                        ↓
                          MP4 ← ffmpeg ← покадровый Chromium ← сцена .html
```

Порядок именно такой: **сначала звук, потом картинка**. Длина ролика определяется записью диктора, а не назначается заранее. Подрезать ничего не нужно.

Рендер идёт в контейнере Claude — на локальной машине ставить нечего. Remotion и GitHub Actions больше не используются.

---

## Формат

| | Вертикаль | Горизонталь |
|---|---|---|
| Размер | 1080×1920, 9:16 | 1920×1080, 16:9 |
| Длина | по дорожке (≈46–50 с) | 7:00 |
| Куда | Shorts, Reels, Telegram | YouTube, Telegram |

Частота кадров — **30 fps** в обоих форматах.

## Состав

**Сценарии** — `PACK-01-shorts.md` (25 вертикальных), `PACK-01-long.md` (5 семиминутных), `PACK-01-otkrytiya.md` (правило открытия), `PACK-01-lanskoy.md` и `PACK-01-long-prompts.md` (промпты генерации).

**Озвучка** — `PIPELINE-zvuk-pervym.md` (регламент), `OZVUCHKA-*.md` (тексты к роликам).

**Код** — `setup.sh` (поднять контейнер), `align.py` (выравнивание текста по дорожке), `settime.py` (подставить раскладку в сцену), `render.py` (покадровый рендер), `shot.py` и `audit.py` (проверки), `i01.html` и `i02.html` (сцены). Тексты озвучки для выравнивателя — `text-I-01.txt`, `text-I-02.txt`.

**Telegram** — `TG-*.md`, готовые посты к каждому ролику.
