# Ланской — моушн-цех

Ролики-инфографика для YouTube Shorts, Reels и Telegram.
Рендерятся **в облаке GitHub Actions**. На локальной машине ничего ставить не нужно.

## Как это устроено

```
сценарий (секунды)  →  React-компоненты  →  GitHub Actions  →  MP4
   src/compositions/      src/components/      бесплатный          ветка renders
                                               раннер Ubuntu       + артефакт
```

Ноутбук не участвует в рендере вообще. Его роль — только открыть браузер.

## Запустить рендер

1. Вкладка **Actions** → слева **Рендер ролика** → кнопка **Run workflow**.
2. Выбрать композицию (`Skidka20`) и качество.
3. Через несколько минут готовый MP4 лежит в двух местах:
   - **Artifacts** внизу страницы запуска — скачать в браузере;
   - ветка **renders**, папка `videos/` — оттуда файл забирается автоматически.

Рендер также запускается сам при любом изменении кода.

## Структура

| Файл | Что там |
|---|---|
| `theme.ts` | Палитра и типографика. Единственный источник правды по цвету. |
| `anim.ts` | Математика времени: секунды→кадры, easing, формат чисел. |
| `ui.tsx` | Кирпичи: титры, карточка, пилюли, столбики, CTA + загрузка шрифта. |
| `Skidka20.tsx` | Сам ролик. Один файл — один ролик. |
| `Root.tsx` | Реестр роликов. Новый ролик регистрируется здесь. |
| `.github/workflows/render.yml` | Облачный рендер. |

Шрифт Golos Text подтягивается с Google Fonts прямо на раннере — бинарников в репозитории нет.

## Правила, на которых держится формат

- **30 fps.** Формат — чистая графика, а не снятое видео: счётчики и полосы на 30 кадрах идут заметно глаже. Решение принято 14.09.2026 после разбора пяти референсов, все они в 30.
- **1080×1920.** Это формат доставки в Shorts, Reels и Telegram. 4K здесь не нужен — он есть в workflow на случай монтажа в другом проекте.
- **Ни одного статичного кадра длиннее 3 секунд.** Либо движение камеры, либо смена плана, либо появление графики.
- **Одно крупное число на ролик.** Два — и ни одно не запомнится.
- **Титры снимаются с озвучки**, а не расставляются на глаз. Массив `CUES` в композиции — это тайм-код реальной речи.
- **Зелёный — деньги, красный — потеря, бирюзовый — бренд.** Других значений у цвета нет.

## Новый ролик

1. Скопировать `Skidka20.tsx` под новым именем.
2. Переписать `CUES` под свой сценарий и поменять данные карточки.
3. Добавить `<Composition>` в `Root.tsx`.
4. Закоммитить — рендер запустится сам.

## Локальный запуск (необязательно)

Если когда-нибудь понадобится студия с превью и ползунком:

```bash
npm install
npm run studio
```

Но для выпуска роликов это не требуется — всё делает облако.
