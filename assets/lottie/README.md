# Lottie — готовые анимации в палитре канала

11 анимаций с LottieFiles, перекрашенных в токены `design-tokens.json`
(зелёный — деньги, красный — потеря, бирюзовый — бренд, серые — поверхности).
Смотреть глазами — **`preview.png`**: слева исходник, справа наша версия.
Откуда каждая и на каких условиях — **`SOURCES.md`**.

| Имя | Что это | Длина | Где пригодится |
|---|---|---|---|
| `chart-grow` | столбики растут, красный первый, зелёный последний, стрелка вверх | 5,0 с | «было → стало», рост дохода |
| `coin-rub` | монета с **₽** (Golos Text Black) крутится и встаёт | 2,55 с | над главным числом, вычеты, кэшбэк |
| `arrow-up` | ступени и стрелка вверх | 1,5 с | рост, прибыль, петлёй на фоне |
| `bars-rise` | столбики на сетке, последний зелёный | 3,0 с | сравнение, «в 3 раза больше» |
| `money-flow` | купюра с монетой по кругу | 3,0 с | перевод, оплата, движение денег |
| `check` | зелёный круг с галочкой | 1,7 с | «готово», «вернули», итог |
| `wallet-cash` | серый кошелёк, в него влетают зелёные купюры | 1,6 с | зарплата пришла, накопил |
| `calculator` | белая иконка калькулятора, знаки меняются | 2,0 с | «считаем», расчёт налога |
| `progress` | бирюзовая полоса заполняется | 2,0 с | набегает вместе с числом |
| `piggy` | зелёная копилка, монета падает | 2,0 с | накопления, подушка |
| `percent` | красный значок **%** на пружине | 2,0 с | налог, ставка, «скидка съедает» |

Все векторные (SVG), без растровых вставок и без английских надписей.

## Как вставить в сцену

1. В сцене — строка с нужными именами, **до** основного `<script>`:

   ```html
   <!-- LOTTIE coin-rub,check,progress -->
   ```

2. В коде — контейнер с размерами и кадр из `seek(t)`:

   ```js
   const coin = LOT.make(E_('lot',{left:'280px',top:'300px',width:'520px',height:'520px'}), 'coin-rub');
   window.seek = t => {
     LOT.at(coin, t - at(6,0.1));                 // один раз с момента в блоке 6
     LOT.at(ok,   t - bs(9), {loop:true});         // по кругу
     LOT.at(bar,  t - t0, {speed:1.45});           // подогнать под число
     LOT.at(x,    t - t0, {from:0, to:0.6});       // только кусок, доли длины
   };
   ```

   До старта стоит первый кадр, после конца — последний. Прозрачность и
   положение контейнера сцена ведёт сама, как у любого элемента.

3. Вписать плеер, помощники и данные — сцена остаётся одним файлом:

   ```bash
   python3 assets/lottie/lottie_pack.py i06.html
   ```

   Повторный запуск перевписывает блок `<script id="lottie-pack">`, руками
   его не править. Дальше как обычно: `render.py` → ffmpeg.

**Почему не autoplay.** Сцена — чистая функция `t` (раздел 2 `OPERATIONS.md`).
Анимация, которая играет сама, при покадровом захвате даёт разный кадр на
разных машинах. `LOT.at()` ставит кадр через `goToAndStop`, поэтому один `t`
всегда даёт один кадр, и прерванный рендер докатывается.

**Шрифт в `coin-rub`.** Знак ₽ — живой текст Golos Text Black, как титры.
В контейнере шрифты ставит `setup.sh`; без них знак упадёт на запасной.

python3 render.py assets/lottie/demo.html frames_demo
ffmpeg -framerate 30 -i frames_demo/f%05d.png -c:v libx264 -crf 16 -pix_fmt yuv420p lottie-demo.mp4

## Переходы

Требование: **плавные и в теме.** Поэтому основа — четыре своих перехода из
предметов ролика (`perehody.js`), и к ним два Lottie, прошедшие замер.

| Переход | Что на экране | Длина | Самый резкий кадр |
|---|---|---|---|
| `PER.coin` | монета с ₽ подброшена, докручивается и летит в камеру; экран проходит сквозь неё | 1,5 с | 25% |
| `PER.bars` | три столбика графика (серый, бирюзовый, зелёный) растут каскадом и уходят вверх | 1,24 с | 15% |
| `PER.graph` | снизу поднимается заливка под растущей линией графика, новый акт — «из-под линии» | 0,95 с | 13% |
| `PER.swipe` | карточка уезжает влево и темнеет, следующая приходит справа, как в приложении | 0,7 с | 6% |
| `tr-stripes` | Lottie: строки выписки, серые → бирюзовый → зелёный | ≈1,2 с | 11% |
| `tr-blocks` | Lottie: ячейки таблицы опускаются, лесенка поверхностей → бирюзовый | ≈3,1 с | 17% |

«Самый резкий кадр» — доля пикселей, сменившихся за один кадр сильнее чем на
40 уровней. Склейка встык — 100%. Отброшены круг (54%), панель (100%) и
всплеск (50%): у них полкадра меняется за один кадр, это рывок.

```js
const t1 = PER.coin(st), t2 = PER.bars(st), t3 = PER.graph(st);
const t4 = PER.swipe(actA, actB);                 // акты — полноэкранные, с фоном
const t5 = LOT.cut(E_('',{left:0,top:0,width:'1080px',height:'1920px',zIndex:50}), 'tr-stripes');
window.seek = t => {
  t1.at(t, swap(2));  t2.at(t, swap(4));  t3.at(t, swap(6));
  const moving = t4.at(t, swap(8));               // true — оба акта видимы
  LOT.cutAt(t5, t, swap(10), {speed:1.9});
};
```

Сцена меняет акт ровно в `swap(i)`. У `coin`, `bars`, `graph` и Lottie-переходов
в этот кадр экран закрыт на 100% — проверено покадрово. `tr.span` и
`LOT.span(h, speed)` говорят, когда переход начнётся и кончится
относительно смены: он не должен налезать на соседний.

**Сколько.** В регламенте белая вспышка — маркер смены акта, одна на ролик.
Крупный переход работает так же, поэтому **один крупный переход на ролик** (монета, столбики,
график), остальные смены — прежним коротким фейдом. Свайп — исключение: он
выглядит как интерфейс, а не как эффект, его можно чаще.

Витрина переходов — `demo-transitions.html`, 14 с, 420 кадров, ошибок в
консоли нет. Замер закрытия Lottie-перехода — `scout/lottie_cover.py`.

## Добавить новую

```bash
# 1. найти на lottiefiles.com/free-animations/<запрос>, взять ссылку .lottie
#    (страницы сайта из контейнера закрыты Cloudflare — ссылку берёт браузер;
#     сам файл с assets-v2.lottiefiles.com контейнер качает свободно)
curl -sSo /tmp/x.lottie <url.lottie>
python3 scout/lottie_scan.py <url.lottie> /tmp/x "название"      # кривые + лист кадров
python3 scout/lottie_recolor.py /tmp/x.lottie --dump             # какие цвета внутри
python3 scout/lottie_recolor.py /tmp/x.lottie assets/lottie/<имя>.json [--as …] [--map …]
# 2. строку в SOURCES.md, строку в таблицу выше, перегенерировать preview.png
# переход — ещё и замер окна закрытия (пишется в сам файл, его читает LOT.cut):
python3 scout/lottie_cover.py assets/lottie/tr-<имя>.json --write
```

Правило отбора: плоская векторная графика без людей, без растровых
вставок, без английских слов и без **$** (у нас рубли — знак меняется
`--text`, если это текстовый слой, иначе анимацию не берём).
