# Запуск снимка роликов: по шагам, без объяснений

Объяснения — в `RANNER.md`. Здесь только что нажать и что написать.

## 1. Проверка (PowerShell)

Открыть PowerShell. Выполнить по одной:

```powershell
git --version
python --version
ffmpeg -version
```

Каждая должна ответить номером версии. Если хоть одна пишет «не является
внутренней или внешней командой» — сначала блок 2. Если все три ответили —
сразу блок 3.

**Про bash спрашивать не надо.** Он раньше был в списке, но воркфлоу
переписан на PowerShell: Git для Windows кладёт `bash.exe` в папку, которой
нет в PATH, и проверка падала на ровном месте.

## 2. Доустановить (только то, чего нет)

```powershell
winget install Git.Git
winget install Python.Python.3.12
winget install Gyan.FFmpeg
```

**Закрыть PowerShell. Открыть заново.** Повторить блок 1.

## 3. Раннер: получить команды в GitHub

Открыть в браузере:

```
https://github.com/MrTailsGH/lanskoy-motion/settings/actions/runners/new?arch=x64&os=win
```

Эта ссылка сразу открывает нужную страницу с вашим токеном.

На странице будет раздел **Download** — три команды, и раздел
**Configure** — ещё одна. Их надо выполнить в PowerShell по порядку,
копируя прямо оттуда.

Начать с того, чтобы перейти в корень диска:

```powershell
cd C:\
```

Дальше копировать команды со страницы GitHub — сначала три из Download,
потом одну из Configure. Она выглядит так:

```
.\config.cmd --url https://github.com/MrTailsGH/lanskoy-motion --token AAAA...
```

Токен живёт час. Не успели — обновить страницу, будет новый.

## 4. Четыре вопроса

`config.cmd` спросит четыре раза. Ответы:

```
Enter the name of the runner group          → просто Enter
Enter the name of this runner               → просто Enter
Enter any additional labels                 → просто Enter (ничего не писать!)
Enter name of work folder                   → просто Enter
```

Должно появиться: `√ Runner successfully added`

## 5. Включить раннер

```powershell
.\run.cmd
```

Должно появиться:

```
√ Connected to GitHub
Listening for Jobs
```

**Это окно не закрывать.** Пока оно открыто, раннер работает.

## 6. Запустить работу

Открыть в браузере:

```
https://github.com/MrTailsGH/lanskoy-motion/actions/workflows/snimok.yml
```

Справа серая кнопка **Run workflow** → откроется окошко с двумя полями →
ничего не менять → зелёная кнопка **Run workflow**.

Через несколько секунд обновить страницу — появится жёлтый кружок, значит
работа пошла. Кликнуть по ней, чтобы видеть лог.

## 7. Что должно получиться

Через пять-семь минут кружок станет зелёным. Внизу страницы запуска —
таблица с разобранными роликами.

**Если кружок красный или работа висит серой** — скопировать ссылку на
страницу запуска из адресной строки и прислать мне. Я прочитаю лог.

## 8. Чтобы не держать окно открытым

Это потом, когда всё заработает. Закрыть окно с `run.cmd` (Ctrl+C),
открыть PowerShell **от имени администратора**:

```powershell
cd C:\actions-runner
.\svc.cmd install
.\svc.cmd start
```

Проверка: `.\svc.cmd status` → должно быть `Running`.

Если после этого запуск упадёт с «Python не найден» — это известная
засада, разбор в `RANNER.md`, шаг 4.

# Пульт цеха: что нажать

Пульт — **не сайт**. На GitHub его не открыть: там лежат исходники, а сам
он должен работать на вашем компьютере. Порядок такой: один раз скачать
папку, дальше — двойной клик по значку.

## 1. Скачать папку (один раз)

Открыть **PowerShell** — обычный, не от администратора: кнопка «Пуск», набрать
`powershell`, Enter. Вставить целиком и нажать Enter:

```powershell
cd $HOME\Documents
git clone https://github.com/MrTailsGH/lanskoy-motion.git
cd lanskoy-motion
.\PULT.bat
```

Если папка уже есть и ругается «already exists» — значит скачивать не надо,
вставить это:

```powershell
cd $HOME\Documents\lanskoy-motion
git pull
.\PULT.bat
```

Должно появиться чёрное окно со строчкой `Пульт цеха: http://127.0.0.1:8765/`
и сам собой открыться браузер.

**Чёрное окно не закрывать.** Пока оно открыто — работает пульт. Закрыть,
когда закончили: Ctrl+C или крестик.

## 2. Значок на рабочий стол (тоже один раз)

Чтобы больше не открывать PowerShell. Вставить в PowerShell:

```powershell
$s = (New-Object -ComObject WScript.Shell).CreateShortcut("$HOME\Desktop\Пульт цеха.lnk")
$s.TargetPath = "$HOME\Documents\lanskoy-motion\PULT.bat"
$s.WorkingDirectory = "$HOME\Documents\lanskoy-motion"
$s.Save()
```

На рабочем столе появится **Пульт цеха**. Дальше — только двойной клик по нему.

## 3. Если что-то пошло не так

**Браузер не открылся сам** — вбить в адресную строку руками:
`http://127.0.0.1:8765/`

**Браузер пишет «не удаётся подключиться»** — закрылось чёрное окно. Открыть
пульт заново.

**Чёрное окно мигнуло и пропало** — значит ошибка, её не видно. Запустить из
PowerShell, чтобы прочитать:

```powershell
cd $HOME\Documents\lanskoy-motion
python pult\pult.py
```

и прислать мне то, что напишет.

**«python не является внутренней или внешней командой»** — Python не в PATH.
Разбор в `RANNER.md`, шаг 4.

**Страница открылась, но кнопки серые** — так и задумано: на этой машине нет
инструмента для этой задачи. Сверху видно, чего не хватает. Сборка ролика
требует bash, node и ffmpeg — это контейнер, дома её не запустить.

## 4. Обновить пульт, когда я что-то поменяю

```powershell
cd $HOME\Documents\lanskoy-motion
git pull
```

Потом запустить как обычно.

## 5. Если ролики не качаются: Browsec

ВПН **в браузере** пульту не помогает. Страница только отдаёт команду, а
качает отдельная программа на компьютере — мимо браузера и его расширений.

В приложении Browsec внизу есть строка **РЕЖИМ** с тремя кнопками.

**Проще всего:** нажать **«Полная защита»** — тогда через ВПН идёт всё, в том
числе пульт и раннер GitHub.

**Список программ помогает не всегда — проверено 20.09.2026.** Python в
`AppData\Local\Python\bin\python.exe` — это программа-посредник: она тут же
запускает настоящую, из папки `pythoncore-3.14-64`, и в сеть ходит уже та.
ВПН закрывает посредника, а качает другая — поэтому ролики так и не
скачались. Если всё-таки хочется список, добавлять надо обе:

```
C:\Users\Misni\AppData\Local\Python\bin\python.exe
C:\Users\Misni\AppData\Local\Python\pythoncore-3.14-64\python.exe
```

Надёжнее «Полная защита».

**Проверять не воркфлоу, а кнопкой.** В пульте есть «Проверить сеть»: за
пять секунд покажет, с какого адреса Python выходит наружу и пустит ли его
YouTube. Гонять ради этого весь снимок — три минуты.

**После любого из двух — перезапустить то, что качает:**

- пульт — закрыть чёрное окно и открыть значок заново;
- раннер — закрыть `run.cmd` и запустить снова (или `svc.cmd stop` и
  `svc.cmd start`, если стоит службой).

Маршруты программа берёт при запуске: включённый после старта ВПН она не
подхватит.

## 6. Совсем без ВПН: принести файл руками

Работает всегда, даже когда ничего не настроено.

1. Скачать ролик любым способом в браузере, где ВПН работает.
2. Положить файл в папку `vhod` внутри `Documents\lanskoy-motion`.
3. В пульте, карточка **«Разобрать свой файл»** — выбрать его в списке и
   нажать «Запустить».

Через полминуты в разделе «Разборы чужих роликов» появится новая карточка:
склейки, переходы, доля покоя, громкость, дрейф. Темпа речи не будет — он
считается по субтитрам, а при ручном скачивании их обычно нет.

## 7. Как папка обновляется

**Сама, при каждом запуске.** Значок «Пульт цеха» перед стартом забирает с
GitHub всё свежее: сцены, скрипты, сам пульт. В чёрном окне первой строкой
видно `Obnovlenie iz GitHub...`. Делать для этого ничего не надо.

**Если пульт уже открыт,** а я что-то поменял — под шапкой появится метка
«на GitHub есть свежее» и кнопка **Обновить**. Нажать, дождаться, потом
закрыть чёрное окно и открыть значок заново: сам пульт читает свой код при
запуске и на лету не меняется. Страница об этом напишет синей полосой,
угадывать не придётся.

**Если обновление не вышло** — в окне будет `Obnovit ne vyshlo`. Это значит,
что на машине правили файлы руками. Пульт всё равно запустится на старой
версии. Прислать мне, что написано в окне, я разберу.

Вручную то же самое:

```powershell
cd $HOME\Documents\lanskoy-motion
git pull
```


## 8. Прогон по роликам нашей ниши

**Из пульта.** Карточка «Снимок чужих роликов»: поставить, сколько взять,
галка «только наша полка» уже стоит. Запустить. Через несколько минут
разборы появятся внизу страницы — кадры, числа, лента времени.

**Из GitHub.** Actions → «Снимок чужих роликов» → Run workflow. Поле
`nisha` стоит галкой по умолчанию. Раннер сам скачает, замерит и закоммитит.

**Что такое «наша полка».** Каналы с категорией `РУ ядро` и `налоги/банки`
в `radar/channels.json` — русские про деньги, бизнес и налоги. Категории
`мир-формат`, `эталон визуала` и `саморазвитие` при включённой галке
пропускаются: разбирать их полезно, но норма приёмки считается по своей
полке, иначе границы перестают что-либо значить.

**Смотреть разобранное.** Раздел «Разборы чужих роликов» в пульте: у
каждого лента из двенадцати кадров — кликнуть, откроется во весь экран,
Esc или клик закроет. Рядом ссылка на оригинал. Само видео мы не храним:
в репозиторий едут кадры, субтитры и числа, иначе он разрастётся.
