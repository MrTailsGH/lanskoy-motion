# Папка входа

Сюда кладутся ролики, скачанные руками, — когда YouTube с этой машины
не открывается, а через браузер с ВПН скачать получается.

Положить `.mp4` (или `.mov`, `.mkv`, `.webm`) сюда → в пульте выбрать его
в карточке **«Разобрать свой файл»** → кнопка.

Субтитры подхватятся, если лежат рядом с тем же именем: `rolik.mp4` и
`rolik.ru.vtt`. Без них считается всё, кроме темпа речи.

Замеры лягут в `Primeri/<имя файла>/`, сводка пересоберётся сама.
**Видео отсюда в репозиторий не едут** — только кадры, субтитры и числа.

Из командной строки то же самое:

```bash
python3 snimok.py --fayl vhod/rolik.mp4
```
